# OpenWebUI macOS Desktop Wrapper

Нативное macOS приложение-обертка для [OpenWebUI](https://github.com/open-webui/open-webui), написанное на Swift и SwiftUI. Позволяет удобно использовать OpenWebUI как отдельное приложение с быстрым переключением между локальным и внешним адресами сервера.

## Основные возможности

*   **Два режима работы**: Мгновенное переключение между локальным адресом (`http://192.168.3.178:2876/`) для использования дома и внешним адресом (`https://gelting735.synology.me:2876/`) для поездок.
*   **Нативное управление**: Панель инструментов с кнопками "Назад", "Вперед", "Обновить" и "Домой".
*   **Индикатор загрузки**: Интегрированный Progress Bar, отображающий текущий статус загрузки страницы.
*   **Умное закрытие**: Приложение полностью завершает работу при нажатии на кнопку закрытия окна (красный крестик).
*   **Сохранение состояния**: Приложение запоминает последний выбранный режим (Local/External) и восстанавливает его при следующем запуске.

## Структура проекта

*   `WebView.swift`: Компонент на базе `WKWebView` для отображения веб-контента.
*   `WebViewModel.swift`: Логика управления URL, навигацией и состоянием загрузки.
*   `ContentView.swift`: Основной интерфейс приложения с панелью инструментов и индикатором прогресса.
*   `OpenWebUIDesktopApp.swift`: Точка входа и управление жизненным циклом приложения.
*   `Info.plist` & `Entitlements`: Настройки безопасности (App Sandbox и App Transport Security) для работы с сетью.

## Как запустить

1.  Убедитесь, что у вас установлен Xcode.
2.  Откройте файл `OpenWebUIDesktop.xcodeproj`.
3.  Выберите цель (Target) "My Mac".
4.  Нажмите `Cmd + R` для сборки и запуска.

## Технологический стек

*   Swift 5.0+
*   SwiftUI
*   WebKit (WKWebView)
*   AppKit (NSViewRepresentable)
